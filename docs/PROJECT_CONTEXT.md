# Project Context: Our Home (Couple Space Platform)

## Overview
Our Home is a private, real-time application for couples featuring shared dashboards, love counters, interactive decision wheels, date planners, memory scrapbooks, sealed time capsule letters, real-time chat with voice notes, daily bonding prompts, and custom soundscapes.

## Tech Stack
- **Frontend**: React 18, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons
- **Backend**: Express + Vite, Node.js
- **Database**: Firebase Firestore & Supabase (PostgreSQL)
- **Authentication**: Firebase Auth & Custom Tenant Pairing
